# ComicStream — Directives pour OpenAI Codex

## 🛡️ Confidentialité & Sécurité
- Ce dépôt est public : ne jamais inclure de tokens d'API, mots de passe, keystores, adresses IP privées réelles, noms d'utilisateurs réels ou identifiants matériels ADB dans le code ou les commits.
- Utiliser les placeholders génériques : `192.168.1.100`, `user`, `0123456789ABCDEF`, `/media/comics/...`.

## ⚙️ Commandes du projet
- Analyse : `flutter analyze`
- Tests unitaires : `flutter test`
- Déploiement / Bump de version : `./scripts/bump_and_push.sh`

## 🔄 Synchronisation du Contexte
- Toute évolution technique, ajout d'une fonctionnalité ou refonte doit être répercutée dans les fichiers de documentation associés (`docs/CONTEXT.md`, `docs/ARCHITECTURE.md`, `docs/ROADMAP.md`, `README.md`).
